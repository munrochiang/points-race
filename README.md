# points-race

競速溜冰**計分賽**的場邊即時記分與建議工具。單一 HTML 檔、**零外部依賴、完全離線**（localStorage 保存，無任何網路呼叫）。

👉 **[開啟工具](https://munrochiang.github.io/points-race/)**

手機用法：用 Safari／Chrome 開上面的連結 → 分享 →「加入主畫面」，之後就是一個離線 app。

## 每一圈兩個輸入

1. **得分號碼** —— 廣播念到時，依進線順序點選（普通圈 2／1 分，最後一圈 3／2／1）
2. **選手位置** —— 追蹤對象這圈在集團的哪裡（前段／後段／已掉隊）

沒聽清楚號碼時按 **⚠️ 沒聽清楚**，不要亂猜 —— 系統會記成「這圈有 N 個名額被不知道是誰的人拿走」，改用區間計算，只會偏保守不會偏樂觀。

## 建議怎麼來的

純規則、離線計算，分三層顯示：

| 層 | 內容 |
|---|---|
| **指令**（大字） | `f(得分狀態, 位置)` —— 任一輸入改變就整句換 |
| **狀態**（小字） | 分數／0 分名額／位置 |
| **觀測到** | 從得分序列與圈速辨識的劇本訊號，依重要性排序只顯示前 3 條 |

核心數字是 **「0 分還剩幾個名額」= 晉級線 − 得分人數** —— 計分賽先比分數再比時間，所以有分的人全部排在 0 分的人前面。

### 圈速是推算的

操作者在每個計分圈報秒時點選，相鄰兩圈的輸入時間差就是圈速。設延遲為 `L`：

```
Δt = (T報秒ₙ₊₁ + L) − (T報秒ₙ + L) = 真實圈速
```

固定延遲在相減時抵消，所以 Δt 對圈速**無偏**；殘餘誤差來自延遲抖動（約 ±1 秒）。因此**測不出 0.5 秒的漂移，但 2～3 秒的加速看得很清楚** —— 而那正是「集團開始搶分」的量級。

漏聽或手慢的那一圈會讓 Δt 偏大、下一圈偏小（成對出現），所以基準用**中位數**而非平均，跳圈的不計入。

## 資料來源

內建組別為 115 年第 17 屆全民有氧盃（2026/08）的計分賽出發名單，取自大會公開的出場序。
選手排序依歷史成績推估（越強越上面），查無紀錄者以 `?` 標記並排在最後。

## 測試

單一檔案無建置，測試用 node ＋ DOM stub 直接 eval 真實程式碼：

```bash
A=$(grep -n '^<script>$' index.html | head -1 | cut -d: -f1)
B=$(grep -n '^</script>$' index.html | tail -1 | cut -d: -f1)
sed -n "$((A+1)),$((B-1))p" index.html > /tmp/main.js
node test/run.js /tmp/main.js test/tbody.js
```
